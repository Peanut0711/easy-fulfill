# UI 디자인 가이드 (커스텀 테마)

상태: **초안**(2026-11-18, [GUI 전면 디자인 개편 계획](ui-redesign-plan.md) 0단계. 2026-11-19 2-1에서 `shared/theme.py`로 적용하며 컨트롤 높이·주의 색을 고침). 값은 2단계 「검토 지점 A」에서 캡처를 보고 확정한다. 확정 전까지 「정할 것」에 남은 항목은 바꿀 수 있다.

이 문서의 값은 `shared/theme.py` 한 곳에서만 코드로 쓴다(2단계부터). 화면 코드에는 색 값·글꼴 크기·여백 수치를 직접 쓰지 않고 기준값 이름이나 부품을 쓴다.

## 원칙

이 앱은 사무실에서 하루 종일 주문·송장을 처리하는 도구다. 모양보다 아래 순서를 앞에 둔다.

1. **다음 동작이 보인다.** 한 구획에서 강조(primary) 버튼은 하나이고, 그것이 작업 순서상 다음 동작이다.
2. **실수를 막는다.** 되돌릴 수 없는 동작(실제 접수·인쇄·발송처리·삭제)은 위험 버튼 모양으로 다른 버튼과 떨어뜨려 두고, 확인 창의 버튼은 「예」가 아니라 동작 이름(「접수하기」)이다.
3. **읽기 쉽다.** 글자 대비 4.5:1 이상, 잘린 글자는 말줄임 + 툴팁으로 원문을 보인다. 색만으로 뜻을 전하지 않는다(✓ ! ✗ 기호를 함께 씀).
4. **손이 덜 간다.** 모든 동작은 키보드로 할 수 있고, 포커스가 늘 보이며, Tab 순서가 화면 순서와 같다. 단축키가 있는 버튼은 툴팁에 단축키를 적는다.
5. **어느 PC에서나 같다.** 100·125·150% 배율에서 겹치거나 잘리지 않는다. 글자가 들어가는 칸에 픽셀 고정 폭을 쓰지 않는다.

### 글꼴

- 글꼴: 맑은 고딕(Malgun Gothic). 굵기는 보통과 굵게 두 가지뿐이므로 굵게는 구획 제목·강조 버튼·표 머리글에만 쓴다.
- 크기(포인트): 본문 **10pt**(현재 9pt에서 키움, 「정할 것」), 보조(상태바·캡션·표 안 보조 글자) 9pt, 구획 제목 10.5pt 굵게. 탭 이름 10pt.
- 숫자 열(건수, 금액, 수량)은 오른쪽 정렬한다.

### 간격·크기 (논리 픽셀, 4의 배수)

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `space.xs` | 4 | 아이콘과 글자 사이, 칩 안쪽 |
| `space.sm` | 8 | 버튼 사이, 라벨과 입력칸 사이, 입력 행 사이 |
| `space.md` | 12 | 카드 안쪽 여백, 카드 사이 |
| `space.lg` | 16 | 탭 페이지 가장자리 여백 |
| `space.xl` | 24 | 큰 구역 사이(드물게) |
| `control.height` | 30 | 버튼, 입력칸, 콤보(9pt 기준. 10pt로 키우면 2-3에서 다시 정함) |
| `control.height.compact` | 26 | 표 위 도구 줄, 표 행 높이 |
| `chip.height` | 22 | 상태 칩, 작은 배지 |
| `button.min_width` | 64 | 글자가 짧은 버튼 |
| `radius.control` / `radius.card` / `radius.chip` | 6 / 8 / 11 | |
| `focus.ring` | 2 | 포커스 테두리 두께(`primary`) |

## 화면 틀

```
┌ 메뉴바 ───────────────────────────────────────┐
│ 탭바: 주문·발송 | 배송추적 | 단건 송장 | 문서 만들기 | 상세페이지 | ⚙ 설정 │
├───────────────────────────────────────────────┤
│ bg.app 바탕, 가장자리 space.lg                 │
│ ┌ 카드(SectionCard) ─────────────────────────┐ │
│ │ ① 제목                         [보조 동작] │ │
│ │ 내용(입력 격자, 표, 목록)                  │ │
│ │ [초기화]              [보조]  [주 동작]    │ │
│ └────────────────────────────────────────────┘ │
│ (카드 사이 space.md)                           │
├ 알림 띠(필요할 때만) ──────────────────────────┤
└ 상태바: 마지막 알림 · · · Google · 인덱스 · 버전 ┘
```

- 탭 페이지는 카드들을 위에서 아래로 쌓는다. 남는 세로 공간은 표·목록·로그 같은 늘어나는 내용이 차지하고, 늘어날 것이 없으면 카드를 위에 붙이고 아래를 비운다(가운데 정렬 안 함).
- 주문·발송처럼 두 단계가 나란히 있는 탭만 좌우 2열(스플리터)을 쓴다. 폭이 좁으면(창 최소 폭) 각 열의 버튼 줄이 겹치지 않아야 한다.
- 탭 순서와 Ctrl+1~6은 유지한다.

## 부품

| 부품 | 규칙 |
|---|---|
| **카드** `SectionCard` | `bg.surface`, `border` 1px, `radius.card`, 안쪽 `space.md`. 제목 줄: 단계 번호(있으면 원 배지) · 제목(10.5pt 굵게) · 오른쪽 보조 동작. QGroupBox와 파란 번호 제목을 대신한다 |
| **버튼** | 높이 `control.height`, 최소 폭 `button.min_width`, 글자 폭보다 늘리지 않는다(폭 나누기 금지). 종류: 주(primary, 채움), 보조(흰 바탕 + `border.strong`), 위험(흰 바탕 + `danger` 글자·테두리), 글자(테두리 없음, 로그 지우기 같은 가벼운 동작) |
| **버튼 줄** `ButtonRow` | 왼쪽: 초기화·위험 동작. 오른쪽: 보조 → 주 동작 순(주 동작이 맨 오른쪽). 버튼 사이 `space.sm`. 폭이 모자라면 줄바꿈하지 않고 창 최소 폭을 지키도록 버튼 글자를 줄인다 |
| **입력 격자** `FormGrid` | 라벨 열(오른쪽 맞춤 아님, 왼쪽 맞춤) · 입력 열 · 보조 버튼 열(주소 검색 등). 필수 칸은 라벨 뒤 `*`, 비어 있으면 `warn`. 오류는 칸 아래 한 줄 `danger` |
| **입력칸·콤보** | 높이 `control.height`, `border.strong`, `radius.control`, 포커스 시 `primary` 테두리 2px. 꺼지면 `disabled.*` |
| **표** | 머리글 `bg.subtle` 굵게, 행 높이 `control.height.compact`, 선택 `primary.subtle`(글자색 유지), 세로 격자선 없음, 가로 구분선 `border`. 숫자 오른쪽, 잘린 칸 툴팁 |
| **빈 상태** `EmptyState` | 표·목록 자리 가운데에 무엇을 하면 채워지는지 한 줄(`text.muted`) + 있으면 주 동작 버튼 하나 |
| **상태 표시** | 기존 `set_status`(✓ ! ✗ + 색) 유지. 칩은 높이 `chip.height` |
| **알림 띠** | 기존 동작 유지(성공 10초 뒤 숨김, 주의·오류는 닫을 때까지). 모양만 테마로 |
| **오버레이** | 시작·작업 중 오버레이는 `bg.surface` 카드 + 진행 표시 + 무엇을 하는 중인지 한 줄 |
| **대화상자** | 버튼은 `QDialogButtonBox`, 동작 이름 버튼, 기본 버튼은 안전한 쪽(위험 동작 확인 창에서는 「취소」가 기본). 가장자리 `space.lg` |
| **탭바** | 높이 36, 선택 탭은 `primary` 아래 줄 2px + 굵게, 마우스 올림 `bg.subtle` |

## 동작 규칙

- 성공은 알림 띠, 사용자가 꼭 읽어야 하는 오류와 되돌릴 수 없는 동작 확인만 대화상자(알림·상태바 계획의 분류 유지).
- 오래 걸리는 작업은 해당 버튼을 끄고 버튼 글자나 작업 중 오버레이로 무엇을 하는 중인지 보인다. 같은 버튼을 두 번 누를 수 없게 한다.
- 꺼진 버튼은 툴팁에 왜 꺼졌는지 적는다(예: 「주문을 먼저 불러오세요」).
- 날짜·시각 표기: 목록 `MM-DD HH:mm`, 오늘·어제는 말로(「오늘 10:21」).

## 검증 규칙

- 색 대비: 2단계에서 `text*` × `bg*` 조합과 버튼 글자 × 버튼 바탕 조합의 대비를 계산하는 테스트를 둔다(본문 4.5:1, 꺼진 글자는 예외).
- 크기: `tools/measure_window_sizes.py` 예산, `tools/capture_screens.py` 125·150%에서 겹침·잘림 없음.
- 직접 지정 금지: 5단계부터 `shared/theme.py` 밖의 색 값·`setStyleSheet`는 테스트가 막는다.

## 정할 것 (검토 지점 A)

- 본문 글꼴 9pt 유지 또는 10pt(읽기 쉬움 ↔ 크기 예산). 10pt면 창 최소 크기 예산(680×560)을 다시 잰다.
- 탭바 모양(아래 줄 방식 / 둥근 탭)과 「⚙ 설정」을 탭바 오른쪽 끝으로 떼어 놓을지.
- 표 밀도(행 28 / 32).
- 바탕 회색(`bg.app`)과 흰 카드의 대비 정도.
