# 화면 확인 체크리스트 (GUI 전면 디자인 개편)

[GUI 전면 디자인 개편 계획](ui-redesign-plan.md)의 `feat/ui-redesign` 브랜치를 **`main`에 합치기 전에** 한 PC 이상에서 실제로 써 보며 확인하는 목록이다. 개발 중에는 화면을 띄우지 않고 캡처(`tools/capture_screens.py`, 배율은 장치 픽셀 비율로 흉내)로만 확인했으므로, 실제 모니터 배율·글꼴·실제 데이터·키보드 사용은 여기서 확인한다.

- 가능하면 **100%(FHD)와 125% 또는 150%** PC를 하나씩 확인한다. 창은 처음 뜬 기본 크기로 한 번, 최소 크기로 줄여서 한 번 본다.
- 운영 시트에 연결된 PC에서 확인할 때 주의: 브랜치 커밋은 `APP_VERSION`을 올리지 않아 「PC버전」 탭에는 `0.0.26`으로 기록된다(어느 PC가 브랜치를 실행 중인지 따로 알린다).
- 확인한 항목은 `- [ ]`를 `- [x]`로 바꾼다. 문제가 있으면 항목 아래에 어떻게 보였는지 적고 화면 캡처를 남긴다.
- 확인 뒤 결정할 것(검토 리스트 R1~R8)은 계획 문서 「검토 리스트」에 있다.

## 확인 기록

| PC | 화면 해상도·배율 | 확인한 날짜 | 확인한 사람 | 결과 |
|---|---|---|---|---|
|  |  |  |  |  |

## 0. 준비

- [ ] 앱을 닫고 소스트리에서 `feat/ui-redesign` 브랜치를 받아(체크아웃) 다시 실행했다.
- [ ] 앱이 오류 없이 뜨고, 창 제목·상태바 오른쪽 아래 버전이 `v0.0.26`이다(브랜치는 버전을 올리지 않음).

## 1. 전체 모양 (테마)

- [ ] 바탕이 옅은 회색이고, 묶음은 흰 카드(둥근 모서리)이며 묶음 제목이 카드 안 왼쪽 위에 굵게 보인다.
- [ ] 글자가 이전(9pt)보다 조금 크고(10pt) 흐리거나 깨져 보이지 않는다(맑은 고딕).
- [ ] 선택한 탭 아래에 파란 줄이 보이고, 탭 글자가 잘리지 않는다.
- [ ] 콤보박스·날짜 칸·숫자 칸의 화살표(⌄ ⌃)가 보이고 눌린다.
- [ ] **Tab 키**로 버튼·입력칸을 옮겨 다니면 파란 테두리(포커스)가 보인다.
- [ ] 메뉴 이름의 단축 글자 밑줄(「파일(F)」의 F)이 늘 보인다(이전에는 Alt를 눌러야 보였음, 검토 리스트 R4).
- [ ] 주황(주의) 글자가 이전보다 조금 진하고 잘 읽힌다.

## 2. 주문·발송 탭

- [ ] ①② 패널이 흰 카드로 나뉘고 제목 앞에 번호 배지(1, 2)가 있다.
- [ ] 「초기화」가 ① 카드 오른쪽 위에 있다(검토 리스트 R6).
- [ ] **125%·150% 기본 창:** 「주문 불러오기 · 복사 · 우체국 접수 엑셀」 버튼이 겹치거나 글자가 잘리지 않는다. 창을 최소 폭으로 줄여도 겹치지 않는다.
- [ ] 다음 동작 강조(파란 버튼)가 순서대로 옮겨 간다: 주문 불러오기 → 우체국 접수 엑셀 → 송장 불러오기 → 접수목록.
- [ ] 실제 주문 엑셀을 불러오면 ① 배지가 ✓(초록)로, 발송 파일을 만들면 ② 배지가 ✓로 바뀐다. 초기화하면 1, 2로 돌아온다.
- [ ] 비어 있는 주문 미리보기 자리가 점선 영역으로 보이고, 엑셀을 끌어다 놓으면 불러와진다.
- [ ] 불러온 주문 미리보기 표의 열·행 색(코드 없음 빨강, 택배 아님 노랑)이 잘 보인다.

## 3. 배송추적 탭

- [ ] 위 줄에 건수·위험 칩(왼쪽)과 「선택 건 추적 중지 · 새로고침 · 폐기/예외 재확인」(오른쪽), 아래 줄에 분류·검색이 있다.
- [ ] 「새로고침」(이전 이름 「배송중 새로고침」) 툴팁에 화면의 추적중 송장만 조회한다고 나온다. 이름이 바뀐 것이 업무에 헷갈리지 않는다.
- [ ] 좁은 창(150%)에서 버튼 글자·건수 글자(「자동 60분」 등)가 잘리지 않는다.
- [ ] 실제 배송중 목록에서 위험 행 색(빨강·주황), 선택 행(옅은 파랑), 열 폭이 괜찮다. 열이 다 들어가지 않으면 머리글이 「…」로 줄어든다.
- [ ] 여러 행을 Ctrl/Shift로 선택해 「선택 건 추적 중지」가 된다.

## 4. 단건 송장 탭

- [ ] 입력 묶음은 위에 붙고, 오른쪽 「오늘 만든 단건 송장」 목록이 아래 끝까지 늘어난다.
- [ ] 수동 모드에서 이름·전화번호·기본주소 라벨에 `*`가 있고, 비어 있으면 주황색이다. 채우면 기본 색으로 돌아오고 「생성」이 켜진다.
- [ ] 「주소 검색」 창: 검색어를 넣고 Enter로도 검색되고, 「확인」이 파란 버튼이다.

## 5. 문서 만들기 탭

- [ ] **100%(900×800):** 스크롤 없이 기본정보·품목·계산 요약·하단 버튼이 모두 보인다.
- [ ] **125%·150%:** 가로 스크롤이 없고, 「초기화 · 엑셀 만들기 · PDF 만들기」 줄이 스크롤하지 않아도 늘 아래에 보인다.
- [ ] 기본정보가 두 칸씩 짝지어 있고 「작성 방식」 라디오가 한 줄 전체를 쓴다. 네이버·쿠팡 주문으로 바꾸면 해당 주문 불러오기 묶음이 보인다.
- [ ] 「품목」 카드 안의 「기준상품」 검색으로 상품을 찾아 선택한 행에 적용된다.
- [ ] 실제로 견적서·거래명세서 엑셀과 PDF를 만들어 내용이 이전과 같다.

## 6. 상세페이지 탭

- [ ] 세 단계가 번호 카드(1·2·3)로 보이고, 네이버 상품번호 입력이 ② 카드 안에 있다.
- [ ] 「HTML 생성」·「WING에 HTML 채우기」가 각 카드의 오른쪽 끝 파란 버튼이고, 「로그인 세션 삭제」는 빨간 테두리 버튼이다.
- [ ] 단계를 마치면 번호가 ✓로 바뀌고, 다른 상품번호를 넣거나 「입력 초기화」를 누르면 ②③이 번호로 돌아온다.
- [ ] 「작업 로그 ▸」를 누르면 로그가 펼쳐지고, 오류가 나면 자동으로 펼쳐진다.
- [ ] 상세 HTML 편집기: 「저장」이 파란 버튼, 「원본으로 되돌리기」가 빨간 테두리 버튼이다. 글자색 견본을 누르면 선택한 글자에 색이 적용된다.

## 7. ⚙ 설정 탭

- [ ] 왼쪽 분류 목록이 넓어지고(140) 선택한 분류가 옅은 파랑 둥근 칸으로 보인다. 경계선이 한 줄이다.
- [ ] 페이지가 창 폭을 더 쓰고(최대 760), 150%에서도 모든 페이지에 가로 스크롤이 없다.
- [ ] 「배송추적」 페이지의 정체시간 숫자 칸이 두 칸씩 2줄이고 값 변경이 저장된다(전원 공유).
- [ ] 「알림」 페이지의 슬랙 미설정 안내가 줄바꿈되고 「Webhook 변경」 버튼이 잘리지 않는다.
- [ ] 「연동」 페이지의 Google 상태·API 키 행이 이전과 같이 동작한다.

## 8. 메뉴·확인 창·상태바

- [ ] 메뉴 이름이 「API·우체국」이고 Alt+A로 열린다(검토 리스트 R7). 메뉴 안 실제 동작 4개는 실행 전 확인 창이 뜬다.
- [ ] 확인 창 버튼이 「예/아니요」, 「확인/취소」처럼 한국어로 나온다(이전에는 Yes/No). 실제 접수·인쇄 확인 창에서 「아니요」를 누르면 아무 일도 일어나지 않는다.
- [ ] 입력칸에서 오른쪽 클릭 메뉴(잘라내기·복사·붙여넣기)가 한국어다.
- [ ] 상태바의 Google·인덱스·버전 칩과 알림 띠(초록·주황·빨강)가 잘 보인다.
- [ ] 작업 중 덮개(회전 표시)가 화면 가운데 카드로 보인다.

## 9. 단축키 (이전과 같아야 함)

- [ ] Ctrl+1~6 탭 이동, Ctrl+O 주문 불러오기, Ctrl+Shift+O 송장 불러오기, Ctrl+Enter 단건 송장 생성이 된다.

## 확인을 마친 뒤

- [ ] 문제가 없으면 계획 문서 「검토 리스트」 R1~R8의 「결정」 칸을 채운다(그대로 / 바꿈).
- [ ] 사용자가 「main에 합쳐」라고 지시하면 합친다. 합치는 커밋에서 `APP_VERSION`을 `0.0.27`로 올리고 계획 문서 「버전 이력 초안」을 [버전 이력](app-version-update-guide.md#버전-이력) 한 줄로 정리한다. `MIN_COMPATIBLE_VERSION`은 올리지 않는다(시트 쓰기 방식 변경 없음).
- [ ] 합친 뒤 각 PC에서 페치 → 풀 하고 이 목록의 1·2장을 한 번 더 본다.
