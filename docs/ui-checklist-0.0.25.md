# 화면 확인 체크리스트 (앱 0.0.25)

창 크기·「설정」 탭 작업(`0.0.9`~`0.0.17`, [계획](gui-window-settings-plan.md))과 알림·상태바·탭 다듬기 작업(`0.0.18`~`0.0.25`, [계획](gui-feedback-tabs-plan.md))을 한 PC에서 실제로 써 보며 확인하는 목록이다. 화면 순서대로 위에서부터 확인한다.

- **(지난번 확인)** 표시는 창 크기·설정 탭 작업을 `main`에 합치기 전(2026-11-18)에 이미 확인한 항목이다. 같은 화면이라 함께 적었다.
- 표시가 없는 항목은 알림·상태바·탭 다듬기 작업에서 새로 바뀐 것이다.
- 확인한 항목은 `- [ ]`를 `- [x]`로 바꾼다. 문제가 있으면 항목 아래에 어떻게 보였는지 적고, 가능하면 화면 캡처를 함께 남긴다.

## 확인 기록

| PC | 화면 해상도·배율 | 확인한 날짜 | 확인한 사람 | 결과 |
|---|---|---|---|---|
|  |  |  |  |  |

## 0. 준비

- [ ] 앱을 닫고 소스트리에서 `main`을 페치 → 풀 한 뒤 다시 실행했다.
- [ ] 창 제목과 상태바 오른쪽 아래가 **v0.0.25**다.

## 1. 메인 창 (지난번 확인)

- [ ] 창을 옮기고 닫았다가 다시 열면 같은 자리, 같은 크기로 뜬다.
- [ ] 모든 탭을 오가도 창 크기가 바뀌지 않는다.
- [ ] 저장한 위치가 없는 PC에서는 화면 가운데에 900×800(FHD 100%)으로 뜬다.

## 2. 주문·발송 흐름 (알림 띠)

- [ ] **주문 불러오기 → 우체국 접수 엑셀:** 「완료」 확인 창 없이 화면 아래에 초록 알림 띠가 뜬다.
- [ ] **띠 버튼:** 「엑셀 열기」를 누르면 엑셀이 열리고, 「폴더 열기」를 누르면 폴더가 열린다.
- [ ] **송장 불러오기 → 일괄 발송 파일:** 같은 방식의 알림 띠가 뜬다.
- [ ] **「접수목록」:** 저장한 뒤 「폴더를 열까요?」 질문 대신 알림 띠가 뜬다.
- [ ] **자동으로 사라짐:** 성공 알림은 10초 뒤 사라지고, 마우스를 올려 두면 사라지지 않는다.
- [ ] **상태바에 남음:** 알림 띠가 사라진 뒤에도 상태바 왼쪽에 같은 문구가 남는다.
- [ ] **확인 창은 그대로:** 실제 접수·발송·인쇄처럼 실행 전에 묻는 확인 창은 예전처럼 뜬다.

## 3. 상태바 (오른쪽 아래)

- [ ] **세 가지 표시:** 「✓ Google」, 「✓ 인덱스 HH:MM」, 「v0.0.25」가 보인다.
- [ ] **누르면 이동:** 각각 누르면 「⚙ 설정」의 연동, 주문·사은품, 프로그램 페이지로 간다.

## 4. 배송추적 탭

- [ ] **가로 스크롤:** 실제 목록에서 기본 창 크기일 때 표 아래에 가로 스크롤바가 없다.
- [ ] **열 숨기기:** 열 머리를 오른쪽 클릭하면 보일 열을 고를 수 있다. 「최근조회」·「스토어」는 기본으로 숨겨져 있다.
- [ ] **숨긴 열 유지:** 고른 열 구성이 앱을 다시 켜도 유지된다.
- [ ] **잘린 글자:** 잘린 칸에 마우스를 올리면 전체 글자가 보인다.
- [ ] **위험 버튼:** 위험 송장이 있으면 「⚠ 위험 n」·「허브」·「수거누락」·「이동」 버튼이 보인다.
- [ ] **위험 거르기:** 위험 버튼을 누르면 그 위험만 보이고, 다시 누르면 전체가 보인다.
- [ ] **건수 줄:** 「마지막 조회 HH:MM · 자동 60분」이 보인다.
- [ ] **빈 목록 안내:** 없는 수취인을 검색하면 표 가운데에 안내 문구가 보인다.

## 5. 단건 송장 탭

- [ ] **(지난번 확인)** 입력 묶음이 이 탭에 붙어 있다. 이름은 「단건 송장 엑셀」로 바뀌었다.
- [ ] **버튼 위치:** 「초기화」·「생성」이 맨 아래 줄에 있고, 「생성」은 파란색이다.
- [ ] **필수 칸:** 수동 모드에서 이름·전화번호·기본주소 중 하나라도 비어 있으면 「생성」이 눌리지 않는다. 마우스를 올리면 빈 칸 이름이 보인다.
- [ ] **Ctrl+Enter:** 누르면 생성되고 알림 띠가 뜬다.
- [ ] **오늘 만든 목록:** 오른쪽 「오늘 만든 단건 송장」에 「시각 · 수취인 · 스토어」로 추가된다.
- [ ] **목록에서 열기:** 목록 항목을 두 번 누르면 엑셀이 열린다.
- [ ] **클립보드 모드:** 네이버·쿠팡 등 클립보드 모드도 예전처럼 동작한다.

## 6. 문서 만들기 탭

- [ ] **배경색:** 다른 탭과 같은 흰색이다(전에는 회색).
- [ ] **버튼:** 「초기화」는 왼쪽 끝에 있고, 「PDF 만들기」는 파란색이다.
- [ ] **성명 표시:** 「성명 *」은 비어 있으면 주황색이고, 입력하면 원래 색으로 돌아온다.
- [ ] **문서 생성:** 문서를 만들면 알림 띠가 뜬다(「PDF 열기」·「폴더 열기」).

## 7. 상세페이지 탭

- [ ] **(지난번 확인)** 상품번호를 「대상 상품」 칸에 한 번만 넣고 HTML 생성과 WING 채우기가 된다.
- [ ] **(지난번 확인)** 끝난 단계 제목에 ✓가 붙고, 작업 로그는 접혀 있다가 오류가 나면 펼쳐진다.
- [ ] **배경색:** 다른 탭과 같은 흰색이다.
- [ ] **편집기 창:** 「HTML 편집」 창을 옮기고 크기를 바꾼 뒤 닫았다가 다시 열면 같은 자리, 같은 크기로 뜬다.
- [ ] **편집기 저장:** 편집기에서 저장하면 확인 창 없이 창이 닫히고 알림 띠가 뜬다.

## 8. ⚙ 설정 탭

- [ ] **(지난번 확인)** 여섯 분류(연동·알림·배송추적·주문·사은품·DB 동기화·프로그램)의 버튼이 예전처럼 동작한다. 재인증, 공유 시트 열기, 키 등록, 사은품 구간 설정을 눌러 보고, DB 동기화는 테스트 모드로 실행한다.
- [ ] **(지난번 확인)** 묶음 제목에 「· 이 PC」·「· 전원 공유」가 붙어 있다.
- [ ] **(지난번 확인)** 연동의 API 키가 키마다 한 줄씩(등록됨/미설정, 「등록」/「변경」 버튼) 보이고, 「연결 해제」는 빨간 테두리 버튼으로 오른쪽 끝에 있다.
- [ ] **(지난번 확인)** DB 동기화에서 테스트 모드를 켜면 주황색 띠가 나타나고 버튼이 「테스트 실행」으로 바뀐다.
- [ ] **결과 알림:** 인덱스 「스프레드시트에서 다시 읽기」, Google 재인증·연결 해제의 결과가 확인 창이 아니라 알림 띠로 뜬다.

## 9. API(개발 중) 메뉴 (지난번 확인)

- [ ] **메뉴 구성:** 메뉴에 불러오기·로그인·출력 대상·「우체국 확인·진단…」과, 구분선 아래 실제 동작 4개(경고 아이콘)만 있다.
- [ ] **확인·진단 버튼:** 「설정 › 프로그램」의 확인·진단 버튼이 예전 메뉴 항목과 같은 창을 연다.

## 10. 단축키

- [ ] **탭 이동:** Ctrl+1~6을 누르면 탭이 순서대로 바뀐다.
- [ ] **송장 불러오기:** Ctrl+Shift+O를 누르면 송장 불러오기 창이 뜬다.
- [ ] **단축키 목록:** 「도움말 › 단축키」에 단축키 목록이 보인다.
- [ ] **기존 단축키:** 기존 단축키(Ctrl+O, Ctrl+C, Ctrl+E 등)가 예전처럼 동작한다.

## 11. 이미지 보기 창

- [ ] 이미지 보기 창을 옮기고 크기를 바꾼 뒤 닫았다가 다시 열면 같은 자리, 같은 크기로 뜬다.

## 확인을 마친 뒤

- 모두 괜찮으면 위 「확인 기록」 표를 채우고, [남은 위험 문서](known-risks.md) 「직접 해야 하는 것」의 알림·상태바 항목을 지운다.
- 문제가 있으면 항목 번호와 어떻게 보였는지 남겨 수정을 요청한다.
- 원래대로 돌려야 하면 이전 버전으로 Pull 하지 말고 문제를 먼저 알린다. `MIN_COMPATIBLE_VERSION`은 올리지 않았으므로 다른 PC는 예전 버전으로도 계속 쓸 수 있다.
