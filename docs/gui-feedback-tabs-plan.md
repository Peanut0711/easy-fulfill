# GUI 알림·상태바와 탭 다듬기 계획

작성: 2026-11-18, 기준 커밋 `55713cf`(앱 버전 `0.0.17`, `main`). 창 크기·설정 탭 계획([gui-window-settings-plan.md](gui-window-settings-plan.md))을 마친 뒤의 다음 UI/UX 작업이다. 4단계 계획에서 「3단계(알림·단축키)」로 미뤄 둔 팝업 줄이기·상태바·단축키를 여기서 한다. 줄 번호는 작업 중 바뀌므로 함수 이름으로 찾는다.

## 목표

1. **일을 멈추게 하는 창을 줄인다.** 성공·완료 알림은 화면 안 알림 띠와 상태바로 보이고, 확인 창은 되돌리기 어려운 동작과 사용자가 꼭 읽어야 하는 오류에만 남긴다.
2. **상태를 늘 보이게 한다.** Google 연결, 주문번호 동기화 시각, 앱 버전을 상태바에 상시 표시해 「⚙ 설정」에 가지 않아도 문제를 알 수 있게 한다.
3. **매일 쓰는 탭의 눈에 보이는 문제를 고친다.** 배송추적 표의 잘리는 열, 단건 송장의 버튼 위치, 문서 만들기의 배경·버튼 강조.

## 현재 상태 (근거)

**확인 창.** `QMessageBox` 호출은 `easy-fulfill.py`에 186곳(정보 41, 경고 107, 오류 22, 질문 16), `tracking/controller.py` 22곳, `documents/quotation_statement_widget.py` 12곳, `ui/gift_*` 5곳이다. 종류별로 나누면 다음과 같다.

| 종류 | 예 | 처리 |
|---|---|---|
| ① 파일을 만든 뒤 「완료」 + 「폴더 열기·엑셀 열기·닫기」 | `export_invoice_excel`(우체국 접수 엑셀), `_save_invoice_file`(일괄 발송 파일), `export_category_excel`(분류 결과), `show_excel_created_message`(퀵 엑셀, 문서 만들기 `on_created`) | **알림 띠**(같은 버튼 포함)로 바꾼다 |
| ② 단순 완료 알림 | 재인증 완료, 연결 해제, 인덱스 되돌리기 완료, 주소 검색 키 저장, 슬랙 테스트 성공, 문서 만들기 「문서를 생성했습니다」, 로그 저장 | **알림 띠**로 바꾼다 |
| ③ 「이미 진행 중입니다」 | DB 동기화, 재인증, 우체국 포털 단계 7곳, 택배사 접수목록 | 상태바 메시지로 바꾸고, 가능한 곳은 진행 중 버튼을 끈다 |
| ④ 입력·선택 안내 | 「먼저 표에서 행을 선택해 주세요」, 「상품번호를 확인하세요」, 「주문번호를 입력해주세요」 | 이번에는 두고, 탭별 단계(D)에서 버튼을 미리 끄는 방식으로 줄인다 |
| ⑤ 실행 전 확인(질문) | API 발송처리, 우체국 실제 접수·인쇄, DB 동기화 실제 실행, 세션·로그인 삭제, HTML 다시 생성 | **그대로 둔다**(B-4에서 「No」면 호출 없음을 테스트로 고정함) |
| ⑥ 오류·실패와 진단 결과 | 시트·API 오류, 우체국 포털 진단 결과 | **그대로 둔다**(읽어야 하는 내용) |

**상태바.** `statusBar().showMessage` 호출은 38곳이지만 대부분 몇 초 뒤 사라지고, 평소에는 「준비」만 보인다. Google 연결 상태(`_google_auth_kind`), 마지막 인덱스 동기화(`_index_sheet_last_sync_display`)는 이미 메모리에 있지만 「설정」 탭 안에서만 보인다.

**배송추적 탭.** 표 열이 11개(수취인명·배송상태·마지막위치·최근이벤트·관리상태·완료·주문번호·등기번호·스토어·최근조회·메모, `_TRACKING_TABLE_COLUMNS`)이고 `resizeColumnsToContents` 뒤 마지막 열만 늘린다. 기본 창(900 폭)에서 「메모」가 잘리고 가로 스크롤이 생긴다. 위험 건수는 「표시 n건 · ⚠️ 위험 n건 (허브 · 수거누락 · 이동)」 한 줄로만 보이고 누를 수 없다. 목록이 비면 빈 표만 보이고, 마지막 새로고침 시각은 보이지 않는다.

**단건 송장 탭.** 퀵 엑셀 묶음(`groupBox`, `_apply_quick_excel_grid_layout`)이 최대 폭 520으로 왼쪽에만 있고 오른쪽은 비어 있다. 「생성」·「초기화」가 입력칸보다 위 첫 줄(스토어 선택 옆)에 있다. 탭 이름은 「단건 송장」, 묶음 이름은 「퀵 엑셀」로 다르다. 수동 모드에서 필수 칸이 비어도 「생성」을 누를 수 있고, 누른 뒤 경고 창으로 알려 준다.

**문서 만들기 탭.** 스크롤 영역(`scrollArea_documents`)의 배경이 창 배경색(회색)이라 다른 탭(흰색)과 달라 보인다(설정 탭은 B-1에서 `setAutoFillBackground(False)`로 맞춤). 하단 「초기화 · 엑셀 만들기 · PDF 만들기」가 같은 모양이고 「초기화」가 바로 옆에 붙어 있다.

**단축키.** Ctrl+O(주문 불러오기), Ctrl+C(복사), Ctrl+E(우체국 접수 엑셀), Ctrl+F(결과 폴더), Ctrl+R(초기화), Ctrl+D(데이터베이스 시트), Ctrl+Q(종료)만 있다. 탭 이동, 송장 불러오기, 단건 송장 생성에는 단축키가 없고, 단축키 목록을 볼 곳도 없다.

**팝업 창 크기.** `ImageDialog` 1024×768, `DetailHtmlEditorDialog` 1280×760 고정이다. 125% 배율 FHD(작업 영역 약 1536×826)에서는 화면을 거의 다 덮고, 위치·크기를 기억하지 않는다.

## C단계: 알림과 상태바 (공통)

### C-1. 알림 띠

- 새 모듈 `shared/ui_notice.py`에 `NoticeBar(QFrame)`를 둔다. 탭 영역 아래·상태바 위에 한 줄로 붙는다. 구성: 종류 표시(✓·!·✗, `set_status`와 같은 색) · 문구 · 버튼 최대 2개 · 닫기(×).
- `MainWindow.notify(kind, text, actions=(), detail="")` 하나로 부른다. `actions`는 `("엑셀 열기", 함수)` 목록이다. 새 알림이 오면 이전 알림을 바꾼다(쌓지 않는다).
- 자동 숨김: 성공(ok)은 일정 시간 뒤 숨기고, 마우스를 올리면 멈춘다. 주의·오류(warn·error)는 닫을 때까지 둔다. 시간은 「정할 것」.
- 같은 문구를 상태바 왼쪽 메시지(`showMessage`)에도 남겨, 띠를 닫은 뒤에도 마지막 알림을 볼 수 있게 한다.
- 위 표 ①의 「완료」 창 네 곳과 `show_excel_created_message`를 `notify("ok", "송장 엑셀 파일을 만들었습니다: 파일이름", [("엑셀 열기", …), ("폴더 열기", …)])`로 바꾼다. 「폴더 열기·엑셀 열기」 실패 시 경고 창은 그대로 둔다.
- 테스트: 알림 띠 동작(종류별 색, 버튼 호출, 자동 숨김·마우스 올림, 새 알림이 이전 것을 바꿈), ① 네 곳이 확인 창 없이 알림을 부르는지(`QMessageBox`를 호출하면 실패하도록 바꿔치기).

### C-2. 상태바 상시 표시

- 상태바 오른쪽에 영구 위젯(`addPermanentWidget`) 세 개: 「Google ✓/!/✗」(누르면 「설정 › 연동」), 「인덱스 동기화 10:21」(실패면 ✗, 누르면 「설정 › 주문·사은품」), 「v0.0.17」(새 버전이 있으면 「v0.0.17 → 0.0.18」, 누르면 「설정 › 프로그램」).
- 값은 이미 있는 상태(`_refresh_google_auth_status_ui`, `_update_index_sheet_sync_label`, 버전 확인 결과)에서 함께 갱신한다. **새 시트 읽기·API 호출은 늘리지 않는다.**
- 테스트: 상태가 바뀔 때 세 위젯 글자·색이 따라 바뀌는지, 누르면 해당 설정 페이지로 가는지.

### C-3. 단순 완료·진행 중 창 정리

- 표 ②를 `notify`로, ③을 `statusBar().showMessage` + (가능하면) 진행 중 버튼 끄기로 바꾼다. ④⑤⑥은 손대지 않는다.
- 바꾼 곳 목록을 이 문서에 표로 남긴다(함수 이름 · 전 · 후).
- 측정: 매일 흐름(주문 불러오기 → 복사 → 우체국 접수 엑셀 → 송장 불러오기 → 일괄 발송 파일)과 단건 송장 1건에서 **성공 경로에 뜨는 확인 창 수**를 C-1 전후로 세어 커밋 본문과 `docs/known-risks.md` 작업 기록에 적는다. 목표는 성공 경로 0개.

## D단계: 탭별 다듬기

### D-1. 배송추적 탭

- **열 표시:** 표 머리 우클릭 메뉴로 열을 보이고 숨긴다. 숨긴 열은 이 PC 앱 설정(`tracking_hidden_columns`)에 저장한다. 기본 숨김 열은 「정할 것」. 열 너비는 내용 기준으로 맞추되 최대 폭을 두고(긴 위치·이벤트 문구는 툴팁), 「메모」가 마지막에 남은 폭을 갖는다. 목표: 기본 창 폭에서 가로 스크롤 없음.
- **위험 요약:** 건수 줄을 「위험 3 · 허브 1 · 수거누락 1 · 이동 1」 버튼형 칩으로 바꾸고, 누르면 그 위험만 거른다(다시 누르면 해제). 거르기는 표시만 바꾸고 시트 읽기를 늘리지 않는다.
- **새로고침 시각:** 건수 줄 오른쪽에 「마지막 새로고침 10:20 · 자동 60분」(자동 끔이면 「자동 꺼짐」).
- **빈 목록 안내:** 행이 0개면 표 가운데에 분류별 문구(예: 「배송중인 송장이 없습니다」, 거르는 중이면 「조건에 맞는 송장이 없습니다 · 거르기 해제」)를 보인다.
- 테스트: 열 숨김 저장·복원, 위험 칩 거르기, 빈 목록 문구, 기본 창 폭에서 가로 스크롤 여부(`tools/measure_window_sizes.py`에 표 필요 폭 추가).

### D-2. 단건 송장 탭

- 탭 이름과 맞춰 묶음 제목을 「단건 송장 엑셀」로 바꾼다(위젯 이름 `groupBox`는 유지).
- 「생성」·「초기화」를 맨 아래 줄로 옮기고 「생성」을 강조(primary)한다. 「초기화」는 왼쪽, 「생성」은 오른쪽.
- 수동 모드에서는 이름·전화번호·기본주소가 다 차야 「생성」이 켜진다(빈 칸 이름을 툴팁으로). 생성 함수의 누락 경고는 안전장치로 남긴다. 클립보드 모드에서는 지금처럼 항상 켠다.
- 오른쪽 빈 공간에 「오늘 만든 단건 송장」 목록(오늘 `output` 폴더에 만든 퀵 엑셀 파일, 시각 · 수취인 · 파일 이름, 두 번 누르면 열기)을 둔다. 로컬 폴더만 읽는다.
- Ctrl+Enter로 생성(E-1과 함께).
- 테스트: 필수 칸에 따른 버튼 켜짐, 버튼 위치·강조, 오늘 목록(임시 폴더).

### D-3. 문서 만들기 탭

- `scrollArea_documents`의 viewport·내용 위젯 배경을 다른 탭과 같게 한다(설정 탭과 같은 방식).
- 하단 버튼: 「초기화」를 왼쪽 끝으로 떨어뜨리고, 주 동작 하나를 primary로 강조한다(어느 쪽인지 「정할 것」).
- `create_document`의 입력 확인에서 필수인 칸(지금은 「성명」)에 표시(라벨 끝 `*`, 비어 있으면 라벨을 주의 색)를 붙인다. 필수 칸을 늘리지는 않는다.
- 「문서를 생성했습니다」·「엑셀 및 PDF 파일을 생성했습니다」 창을 C-1 알림(「파일 열기」·「폴더 열기」)으로 바꾼다.
- 테스트: 배경색(팔레트 확인), 버튼 역할, 생성 후 확인 창 없이 알림.

## E단계: 단축키와 팝업 창

### E-1. 단축키

- 탭 이동 Ctrl+1~6(주문·발송, 배송추적, 단건 송장, 문서 만들기, 상세페이지, 설정). 송장 불러오기 Ctrl+Shift+O(「파일」 메뉴 항목에 표기). 단건 송장 생성 Ctrl+Enter(그 탭에서만).
- 기존 단축키(Ctrl+O·C·E·F·R·D·Q)는 바꾸지 않는다. Ctrl+R(초기화)·Ctrl+F(결과 폴더)가 흔한 뜻(새로고침·찾기)과 다르지만, 이미 손에 익었을 수 있어 「정할 것」에만 적는다.
- 「도움말 › 단축키」 메뉴로 단축키 목록 창을 연다(표 하나, 메뉴 동작에서 자동으로 모음).
- 테스트: 단축키 충돌 없음(모든 `QAction` 단축키 중복 검사), 탭 이동.

### E-2. 팝업 창 크기와 위치

- `DetailHtmlEditorDialog`·`ImageDialog` 기본 크기를 `shared/window_geometry.py`의 방식으로 화면 작업 영역에 맞춘다(최대 1280×760·1024×768, 작업 영역의 90% 안).
- 닫을 때 크기·위치를 이 PC 앱 설정(창 이름별)에 저장하고, 다음에 같은 화면 구성이면 되살린다(메인 창 A-3과 같은 규칙).
- 테스트: FHD 100%·125% 작업 영역에서 기본 크기, 저장·복원.

## 하지 않을 것

- 실행 전 확인 창(표 ⑤)과 오류·진단 결과 창(⑥)을 없애거나 알림 띠로 바꾸는 것.
- 공유 시트 쓰기 방식 변경. 따라서 `MIN_COMPATIBLE_VERSION`은 올리지 않는다. 열 숨김·창 위치는 이 PC 앱 설정에만 저장한다.
- 새 시트 읽기·API 호출 추가(상태바·위험 칩·오늘 목록은 이미 있는 값과 로컬 파일만 쓴다).
- 우체국 실제 접수·인쇄, 네이버 발송처리 API, 쿠팡 WING 저장, 운영 Google 시트 쓰기 실행.

## 하위 작업과 커밋

| 순서 | 작업 | 앱 버전 |
|---|---|---|
| C-1 | 알림 띠, 파일 생성 「완료」 창 네 곳 대체 | 올림 |
| C-3 | 단순 완료·진행 중 창 정리, 성공 경로 확인 창 수 측정 | 올림 |
| C-2 | 상태바 상시 표시 | 올림 |
| D-1 | 배송추적 열·위험 칩·새로고침 시각·빈 목록 | 올림 |
| D-2 | 단건 송장 버튼·필수 칸·오늘 목록 | 올림 |
| D-3 | 문서 만들기 배경·버튼·필수 표시·완료 알림 | 올림 |
| E-1 | 단축키와 단축키 목록 | 올림 |

권장 순서는 위 표 순서다. C-1이 나머지의 바탕(알림을 보일 자리)이고, C-3이 체감 효과가 가장 크다. C-2는 C-1·C-3에서 창 대신 보일 상태를 정리한 뒤 붙인다.

## 검증

- 하위 작업마다 전체 테스트 `python -m unittest discover`가 수정 전과 같은 결과(새 테스트 제외)인지 확인한다.
- `tools/measure_window_sizes.py`로 창·탭 최소 크기를 수정 전후로 잰다. 창 최소 크기 예산(680×560)을 넘지 않는다.
- Windows 맑은 고딕 100%에서 바뀐 화면을 캡처해 확인한다. 알림 띠는 성공·주의·오류 세 종류를 캡처한다.
- C-3 측정(성공 경로 확인 창 수)은 전후 값을 기록한다.

## 진행 규칙

`AGENTS.md`를 따른다. 작업 브랜치(`feat/feedback-tabs`)에서 하위 작업마다 커밋·푸시하고, 앱 코드를 바꾸는 커밋마다 `APP_VERSION` 세 번째 숫자를 올리고 버전 이력을 적는다. `docs/known-risks.md` 「작업별 기록」에 이어서 기록하고, 실서비스로 확인하지 못한 것은 「실서비스로 확인하지 못한 것」에 적는다. 모든 단계를 마친 뒤 한 PC에서 확인하고 `main`에 합친다.
