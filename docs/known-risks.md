# 남은 위험과 버그 수정·반응성 개선 작업 기록

2026-11-17 기준(앱 버전 `2026.11.17.4`, 커밋 `2388c34`). 「easy-fulfill 버그 수정 및 반응성 개선」 작업과 그 후속 수정 이후에 남은 위험과, 작업별 결과를 정리한다.

검증 원칙:

- 각 수정은 문제를 재현하는 테스트를 먼저 만들어, 수정 전 코드에서 실패하는 것을 확인했다.
- 반응성 항목은 같은 조건에서 전후를 재고 중앙값으로 비교했다.
- 우체국 실제 접수와 인쇄, 쿠팡 WING 저장과 검수 요청, 네이버 발송처리 API는 실행하지 않았다.
- 운영 Google 스프레드시트에는 쓰지 않았다. 실서비스 확인은 읽기 전용으로만 했다.

## 1. 직접 해야 하는 것

| 위험 | 할 일 |
|---|---|
| 구버전 PC 덮어쓰기: 버전 차단 장치가 없는 이전 버전 PC는 예전 방식으로 메모와 인덱스를 덮어쓸 수 있다 | 4대 모두 앱을 닫고 소스트리에서 Pull 한 뒤 다시 실행한다. 「PC버전」 탭에 모두 최신 버전으로 나오면 끝이다([업데이트 안내](app-version-update-guide.md)) |
| 실제 OZ Viewer 인쇄 창: 프린터 선택 칸(ComboBox/SysListView32)이 없는 창이면 인쇄가 멈춘다. 잘못 인쇄되거나 인쇄 완료로 기록되지는 않는다 | 다음 실제 인쇄 때 정상 진행되는지 확인한다 |
| 화면 글자: 새 버전 안내 창과 환경설정 「프로그램 버전」 묶음을 한글 글꼴이 있는 화면에서는 확인하지 못했다(동작은 화면 없는 환경에서 확인함) | Pull 한 뒤 한 번 확인한다 |
| 첫 실행 시 시트 변경: 처음 실행하는 PC가 「설정」에 `min_app_version`을 추가하고 「PC버전」 탭을 만든다 | 알고만 있으면 된다 |

## 2. 줄였지만 남아 있는 것

| 위험 | 현재 상태 |
|---|---|
| 읽은 뒤 쓰기까지의 틈(M열 관리상태, 주문번호 인덱스, 설정 저장) | Sheets API에는 조건부 쓰기가 없어 읽기와 쓰기 사이(1초 미만)에 다른 PC가 같은 칸을 바꾸면 덮어쓴다. 다시 누르거나 다음 반영 때 복구된다 |
| 문의 폴링 중복 알림 | 선점을 쓴 뒤 2초 기다렸다 다시 읽어 확인한다. 두 PC의 쓰기가 2초 넘게 벌어져 도착할 때만 중복될 수 있다 |
| 버전 차단의 예외 | 공유 최소 버전을 읽지 못하면(네트워크 오류) 쓰기를 막지 않는다 |
| 새 버전 안내 지연 | 실행 중에는 1시간마다 확인하므로 최대 1시간 늦게 뜰 수 있다 |
| 탭 이름 변경 | 캐시한 탭이 없어지면 바로 다시 열어 오류는 나지 않는다. 대신 원래 이름의 빈 탭이 새로 생기고 예전 데이터는 이름을 바꾼 탭에 남는다(캐시 도입 전과 같은 동작). 송장추적·설정·문의알림·PC버전 탭 이름은 바꾸지 않는다 |

## 3. 운영할 때 주의할 것

- **버전 올리기:** `AGENTS.md` 규칙에 따라 앱 코드를 바꾸는 커밋마다 `APP_VERSION`을 올린다. `MIN_COMPATIBLE_VERSION`은 공유 시트 쓰기 방식이 호환되지 않게 바뀔 때만 올린다.
- **개발 PC:** 운영 시트에 연결된 PC에서 푸시하지 않은 더 높은 버전을 실행하면 다른 PC들에 새 버전 안내가 뜬다. `MIN_COMPATIBLE_VERSION`까지 올린 상태였다면 다른 PC들의 쓰기도 멈춘다.
- **Google 읽기 한도:** 같은 계정의 모든 PC가 분당 60회 읽기 한도를 함께 쓴다. 요청 수를 크게 줄였지만, 대량 작업이 겹치면 잠깐 429 오류가 날 수 있다.
- **안내 끄기:** 「새 버전 안내 무시」를 켠 PC는 업데이트를 놓치기 쉽다.

## 4. 실서비스로 확인하지 못한 것

가짜 API, 모의 화면, 가짜 창으로만 검증했다.

- 우체국 접수 재시도 중복 방지(A5)
- 인쇄 창 확인(A6). 실제 Windows 표준 인쇄 창과 메시지 상자로 판별은 확인했다.
- 네이버 발송 API 행 처리(A7)
- 우체국 포털 로그인 대기(C7a)
- 창 닫을 때 남은 저장(A3)
- 프로필 잠금(B7)
- 버전 기록·차단·새 버전 안내

실서비스에서 읽기 전용으로 확인한 것:

- 시트 인덱스 폴링(C6)
- 탭 속성 캐시
- 없는 탭 오류 문구
- 네이버 상세 이미지(C7b, 상품 12442523238)
- WING 조회
