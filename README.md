# Easy Fulfill

오픈마켓(스마트스토어, 쿠팡 등)에서 주문한 제품 리스트 엑셀 파일을 입력받아, 작업자가 출고를 쉽게 할 수 있도록 작업지시서와 송장 양식을 자동 생성하는 Python GUI 프로그램입니다.

## 요구사항

- Python 3.12.2
- PySide6 6.8.1
- pandas 2.2.1
- openpyxl 3.1.2

## 설치 방법

1. 필요한 패키지 설치:
```bash
pip install -r requirements.txt
```

## 실행 방법

Windows에서는 `run.bat`을 실행하는 방법을 권장합니다. `.venv`를 만들고 `requirements.txt`의 의존성을 자동으로 맞춘 뒤 프로그램을 시작하므로, 상세페이지의 쿠팡 연동에 필요한 Playwright도 함께 설치됩니다.

```bat
run.bat
```

이미 필요한 패키지를 설치한 환경에서는 다음처럼 직접 실행할 수 있습니다.

```bash
python easy-fulfill.py
```

## 기능

- 엑셀 파일(.xlsx) 선택
- 선택된 파일 경로 표시
- 작업지시서 생성 (개발 중)

## 네이버 상세 → 쿠팡 HTML 작성용 변환

네이버 SmartEditor ONE 상세를 읽어 텍스트는 HTML로, 이미지는 쿠팡 CDN 주소로 변환합니다. 쿠팡의 상품 등록·수정·임시저장은 수행하지 않습니다.

쿠팡 게시 과정에서 일부만 사라지는 문제를 피하기 위해 상세 본문의 장식용 이모지(🧩, ⚙️, 📐, 🔹, 🔌, 🔧, 📦, ⚠️ 등)는 변환 시 제거합니다. 목록의 글머리표·들여쓰기와 사양에 쓰인 ×, ≥, ±, °, Ω 등은 유지합니다.

한 상품을 준비만 하려면 다음을 실행합니다.

```bash
python naver_to_coupang_html.py 13204504134 --prepare-only
```

여러 상품은 상품번호를 줄바꿈으로 적은 UTF-8 텍스트 파일을 준비한 뒤 실행합니다.

```bash
python naver_to_coupang_html.py --list product_numbers.txt --upload
```

새로 업로드할 이미지가 있을 때 전용 쿠팡 WING 브라우저의 로그인 권한을 확인합니다. 기존 CDN 이미지만 재사용하거나 이미지가 없으면 브라우저·로그인 없이 HTML을 생성합니다. 로그인 세션은 로컬 `output/coupang-browser-profile`에만 저장되며, 일반 Chrome 로그인과는 별도입니다. 완료된 상품별 `output/detail-preview/<상품번호>/coupang-paste.html` 파일의 내용을 쿠팡 **기본 등록 → HTML 작성**에 붙여 넣으면 됩니다.

화면의 `저장된 로그인 정보`는 로컬 저장 여부를 나타냅니다. 새 이미지 업로드 시 로그인 필요 응답과 접근 차단(403)·요청 제한(429)·서버/통신 오류를 구분하며, 차단이나 통신 오류만으로 재로그인을 요구하지 않습니다. 여러 상품 처리 중 연결에 실패해도 CDN 이미지를 재사용할 수 있는 상품의 HTML은 계속 생성합니다.

기존 쿠팡 상품의 옵션별 이미지 상세를 공용 HTML로 바꾸는 시험 도구는 다음처럼 실행합니다. 기본 실행은 HTML을 화면에 채운 뒤 저장하지 않고 종료합니다.

```bash
python coupang_detail_replace.py 13204504134 16078736117
```

`--apply`는 화면을 확인한 뒤 `APPLY`를 한 번 더 입력해야만 **수정 및 검수 요청**을 보냅니다.

GUI의 **상세페이지** 탭에서도 같은 단건 작업을 할 수 있습니다.

1. **쿠팡 로그인 연결/갱신**을 눌러 WING에 직접 로그인합니다. 이후에는 이 PC의 로컬 브라우저 세션을 재사용하며, 쿠팡 ID·비밀번호는 프로그램에 저장하지 않습니다.
2. **상품 상세 HTML 만들기**에 네이버 상품번호를 입력하고 HTML을 생성합니다. 이미지 업로드 진행률은 팝업과 작업 로그에서 확인할 수 있습니다. 이전 결과가 있으면 다시 생성할지 확인합니다.
   - **유튜브 영상:** 네이버 상세의 YouTube 삽입 영상을 원래 순서대로 재생용 HTML에 포함합니다. 일반 영상·단축 주소·Shorts를 인식하며, 생성 로그와 `report.json`에 영상 개수를 기록합니다. 지원하지 않거나 주소를 읽지 못한 영상은 경고합니다. 로컬 미리보기의 재생은 YouTube의 외부 재생 설정과 브라우저 환경에 따라 제한될 수 있으므로, WING 적용 후 실제 상품에서도 확인하세요.
3. 생성이 끝나면 HTML 편집 창이 열리고, 생성한 상품번호가 **쿠팡 상품 HTML 적용**의 네이버 상품번호에 자동 입력됩니다. 편집 창에서는 PC/모바일 미리보기, 항목 선택·삭제, 실행 취소, 저장(`Ctrl+S`)을 사용할 수 있습니다. 여백·정렬·서식·순서 등을 수정해도 미리보기 스크롤 위치가 유지됩니다. 저장 완료 팝업에서 **OK**를 누르면 편집 창이 닫힙니다.
   - **영상 미리보기:** 편집창과 **미리보기** 버튼은 이 PC의 HTTP 주소로 HTML을 열어 YouTube에 재생 출처를 전달합니다. 별도 서버 실행은 필요 없으며, 편집창용 서버는 창을 닫으면 종료되고 브라우저용 서버는 프로그램 종료 시 정리됩니다. 저장된 HTML을 탐색기에서 직접 더블클릭하면 여전히 오류 153이 발생할 수 있으므로 프로그램의 미리보기 기능을 사용하세요. 저장·복사하는 HTML에는 임시 미리보기 주소가 들어가지 않습니다.
   - **여백 추가:** 미리보기에서 항목을 선택하고 **선택 영역 위/아래**, 간격(12·24·48px 또는 직접 입력)을 정한 뒤 **여백 추가**를 누릅니다. 클릭한 항목 바로 앞뒤에 여백이 들어갑니다. 여러 항목은 연속 선택해야 하며, 선택 범위의 맨 위·아래에 추가됩니다. 목록 항목 사이에도 추가할 수 있고, 기존 간격에 지정한 높이가 더해집니다.
   - **여백 수정:** 점선으로 표시된 여백을 클릭하고 높이를 입력한 뒤 **높이 변경**을 누릅니다. **여백 삭제** 또는 `Delete`/`Backspace`로 제거하고, `Ctrl+Z`로 추가·변경·삭제를 취소할 수 있습니다. 일반 컴포넌트도 미리보기에서 선택 후 두 키로 삭제할 수 있습니다. 점선과 높이 안내는 편집 미리보기에만 표시되며 저장·복사하는 HTML에는 포함되지 않습니다.
   - **이미지 묶음:** 네이버의 2·3열 묶음은 원본의 가로 비율을 유지하며, 모바일에서도 같은 행으로 축소됩니다. 원본 비율이 없으면 이미지의 가로·세로 비율로 계산합니다. 편집창에서는 묶음 전체를 선택·이동·삭제하고 묶음 앞뒤에 여백을 추가합니다. 묶음의 개별 이미지 정렬·분리는 지원하지 않습니다. 새로 생성한 HTML부터 적용되며, 이전 중간 결과를 CDN HTML로 재변환할 때는 이미지 크기 정보가 있으면 묶음 비율을 복원합니다.
   - **목록·문단 서식:** 하위 목록과 문단별 줄바꿈, 빈 문단, 번호 목록의 시작 번호를 보존합니다. 원문에 명시된 글자 크기·색상·정렬·줄높이를 옮기고, 문단 간격·글머리표·들여쓰기는 HTML 내부에 지정해 외부 사이트의 기본 CSS에 영향을 덜 받도록 합니다. GUI 미리보기·복사·WING 입력은 같은 `coupang-paste.html`을 사용합니다. 이미 합쳐진 하위 목록은 기존 결과만으로 복원할 수 없으므로, 편집본을 백업한 뒤 네이버 원문에서 다시 생성해야 합니다. 쿠팡의 저장 후 정제나 실제 상품 화면까지 동일함을 보장하지는 않으므로 WING 미리보기와 적용 결과를 확인하세요.
   - **항목 이동:** 문단·제목·이미지·여백을 선택하고 **위로 이동 / 아래로 이동**을 누르면 바로 앞·뒤 항목과 자리를 바꿉니다. 연속 선택한 여러 항목도 함께 이동합니다. 맨 위·아래 또는 비연속 선택에서는 해당 버튼이 비활성화됩니다. 서로 다른 본문 묶음·인용구·목록을 넘을 때는 필요한 부분만 나눠 원래 태그와 서식을 유지합니다. 이동 후 선택이 유지되며 저장·복사·`Ctrl+Z`를 지원합니다.
   - **정렬:** 미리보기에서 본문·제목·인용구 문단·이미지 등을 선택한 뒤 상단의 **왼쪽 / 가운데 / 오른쪽**을 누릅니다. 여러 요소에 한 번에 적용할 수 있고, 정렬이 서로 다르면 버튼이 선택되지 않은 상태로 표시됩니다. 이미지 크기와 상하 여백은 유지하며, 추가한 빈 여백은 정렬 대상에서 제외합니다. 변경은 저장·HTML 복사에 반영되고 `Ctrl+Z`로 취소할 수 있습니다. 가로폭을 꽉 채운 이미지·표의 너비 조절은 지원하지 않습니다.
   - **굵기·글자 크기:** 본문·제목·인용구 문단 또는 표를 클릭한 뒤 **굵게**로 적용·해제하거나 크기를 `px` 단위로 입력하고 **크기 적용**을 누릅니다. 클릭으로 선택한 문단·요소의 텍스트 전체에 적용되며 여러 요소도 함께 바꿀 수 있습니다. 굵기가 섞여 있으면 첫 클릭에 모두 굵게, 다음 클릭에 모두 보통 굵기로 바뀝니다. 서로 다른 글자 크기는 **혼합**으로 표시됩니다. 이미지·빈 여백에는 적용하지 않으며, 저장·복사·실행 취소를 지원합니다.
   - **글자색:** 텍스트 컴포넌트를 선택하고 검정·진회색·빨강·주황·파랑·초록 색상칩을 누르면 바로 적용됩니다. 색상칩에 마우스를 올리면 이름과 HEX 코드가 표시되고 현재 색상에는 선택 표시가 붙습니다. **다른 색상…**을 누르면 색상을 직접 선택하거나 선택창의 **HTML** 칸에 `#336699` 같은 HEX 코드를 입력할 수 있습니다. 여러 컴포넌트를 함께 선택할 수 있으며 내부 강조 글자·링크를 포함한 텍스트 전체에 적용됩니다. 서로 다른 색상은 **색상 혼합**으로 안내합니다. 선택창에서 취소하면 변경하지 않으며 저장·HTML 복사·`Ctrl+Z`를 지원합니다. 이미지·빈 여백·이미지 묶음에는 적용하지 않습니다.
4. 기존 쿠팡 상품에 적용할 때는 쿠팡 등록상품 ID를 입력한 뒤 **WING에 HTML 채우기**를 누릅니다. 저장된 `coupang-paste.html`이 있어야 하며, 기본 등록 → HTML 작성 전환과 HTML 입력까지만 자동 수행합니다. 저장은 열린 WING 화면에서 직접 진행합니다. **수정 및 검수 요청** 후 **수정요청이 완료되었습니다.** 팝업에서 **닫기**를 누르면 해당 작업의 Chromium 창이 자동 종료됩니다. **상품목록** 버튼이나 다른 오류·확인 팝업에는 적용되지 않습니다. 직접 WING 창을 닫는 경우에도 작업 로그에 창 닫힘 감지가 기록되고, 작업 종료·종료 버튼 비활성화·입력 초기화가 자동으로 처리됩니다. 창을 닫지 않고 취소할 때만 **WING 작업 종료**를 누릅니다.

`입력 초기화`는 네이버 상품번호 두 항목과 쿠팡 등록상품 ID만 비웁니다. 작업 로그, 로그인 세션, 생성 결과 파일은 유지합니다. 작업 로그는 화면에서 지우거나 복사·파일 저장할 수 있습니다.

## 프로젝트 구조

```
easy-fulfill/
├── easy-fulfill.py      # 메인 프로그램 파일
├── google_sheets_oauth.py  # Sheets OAuth 공통 (GUI·database-sync)
├── database-sync.py     # 스프레드시트 동기화 (동일 google-oauth)
├── requirements.txt     # 필요한 패키지 목록
├── README.md           # 프로젝트 설명
├── google-oauth/       # Google OAuth (로컬 전용, .gitignore)
│   ├── credentials.json  # GCP에서 받은 클라이언트 JSON (수동 배치)
│   └── token.json        # 로그인 후 자동 생성
└── ui/                 # UI 파일 디렉토리
    └── main_window.ui  # Qt Designer UI 파일
```

`google-oauth` 안의 파일은 Git에 올리지 마세요. 설정 방법은 [docs/google-sheets-oauth-implementation.md](docs/google-sheets-oauth-implementation.md)를 참고하세요.
